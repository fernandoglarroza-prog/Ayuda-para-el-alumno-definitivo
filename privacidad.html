Privacidad

Esta página explica qué información utiliza Ayuda para el Alumno para funcionar, moderar aportes y conocer de forma general cómo se usa el sitio.

Métricas de navegación

Registramos eventos técnicos y agregados, como una visita de página, la apertura de una sección o el uso de ciertos filtros. La medición propia del sitio no guarda el texto escrito en búsquedas ni consultas.

Aportes de material

Cuando una persona aporta un archivo, se procesan la materia seleccionada, el título, la descripción, el año académico, los datos técnicos del archivo y, si decide informarlos, nombre y correo electrónico. El archivo queda privado y pendiente de revisión antes de una eventual publicación.

Para limitar abuso automatizado, el sistema puede generar una huella técnica no reversible a partir de la dirección de red de la solicitud. No se utiliza esa huella para identificar públicamente a la persona.

Relatos anónimos de salud mental

En el espacio “Una mente sana es posible” existe un formulario para compartir relatos de manera anónima. No se solicita nombre, correo electrónico, teléfono ni usuario. Se guarda el texto enviado, la decisión de autorizar o no una eventual publicación anónima y los datos internos necesarios para su moderación.

Los relatos llegan como pendientes y sólo pueden ser vistos por personal autorizado del proyecto. Si una persona autorizó la publicación y el relato es aprobado, se conserva únicamente la versión moderada que se mostrará en el Muro de voces y se elimina el texto original pendiente. Si se decide mantenerlo privado o rechazarlo, el texto original también deja de conservarse. Estos mensajes pueden contener información sensible, por lo que se aplica un criterio de minimización, revisión previa y acceso restringido.

Proveedores técnicos

El funcionamiento utiliza servicios de infraestructura como Vercel, Supabase y Google Drive. Los enlaces externos, por ejemplo WhatsApp, Instagram o sitios oficiales, se rigen por las políticas de esos servicios cuando salís de Ayuda para el Alumno.

Retiro, corrección o consulta

Si necesitás pedir la corrección o retiro de un material, o hacer una consulta de privacidad, escribinos a ayudaparaelalumnouno@gmail.com. Indicá con claridad cuál es el contenido involucrado.

Carácter del proyecto

Ayuda para el Alumno es una iniciativa estudiantil independiente y no es un sitio oficial de la Universidad Nacional del Oeste. Para decisiones administrativas o académicas importantes se recomienda verificar siempre la fuente oficial correspondiente.
