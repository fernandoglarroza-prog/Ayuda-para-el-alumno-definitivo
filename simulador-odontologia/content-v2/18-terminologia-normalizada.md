# 18 · Terminología anatómica normalizada para el simulador

## Objetivo
Evitar que distintas fichas utilicen nombres diferentes para la misma estructura y permitir que el estudiante reconozca tanto la **Terminologia Anatomica contemporánea** como denominaciones clásicas todavía frecuentes en bibliografía/cátedra.

## Regla editorial
- Título principal: término anatómico actual en español.
- Entre paréntesis: sinónimo clásico o de uso docente cuando aporte valor.
- Nunca mezclar dos denominaciones sin explicar que son sinónimos.
- En buscador, aceptar ambos nombres.
- En examen, priorizar el término actual, pero aceptar el clásico correcto.

# Radiología

| Preferido | Evitar/confundir | Nota |
|---|---|---|
| Reconstrucción multiplanar (MPR) | “vista 3D” para todo | MPR y render 3D no son equivalentes. |
| Radiolúcido/radiopaco | oscuro/claro como única definición | Usar terminología radiológica. |
| Corticalización/corticación | borde blanco | Describir estructura y contexto. |
| Volumen CBCT | tomografía 3D como término impreciso | Puede usarse coloquialmente, pero el contenido técnico debe decir CBCT. |

# Nombres que requieren validación específica con la cátedra
1. Espina de Spix vs língula mandibular.
2. Cavidad glenoidea vs fosa mandibular.
3. Pterigoideo interno/externo vs medial/lateral.
4. Maxilar interna vs arteria maxilar.
5. Dentario inferior vs alveolar inferior.
6. Denominaciones de nervios palatinos en textos clásicos.
7. Relación céntrica/oclusión céntrica: no normalizar hasta conocer la escuela conceptual usada por docentes.

# Regla para el buscador y examen
Cada estructura deberá tener `nombre_preferido`, `sinonimos[]` y `terminos_clasicos[]`. El buscador debe indexar todos; la interfaz debe mostrar el nombre actual y, cuando sea útil, el clásico entre paréntesis. En respuestas abiertas, ambos deben considerarse correctos si designan inequívocamente la misma estructura.
